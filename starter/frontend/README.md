# Frontend starter

Create the two Vue 3 + TypeScript + Vite apps here:
- `public-site`: SSG candidate POC, do not lock final SSG before acceptance tests.
- `admin-cms`: Vue SPA, standard Vite build.

Do not commit a fabricated package-lock/pnpm-lock file. Generate the lockfile using the package manager and versions selected by the team, then commit it.
